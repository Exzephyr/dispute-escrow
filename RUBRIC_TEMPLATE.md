# Rubric Examples

## Code Review
Deliverable must contain: ≥3 specific issues, each with line/function ref, each explaining WHY, ≥1 security/correctness issue, constructive tone.
Score: 90-100 all met | 60-89 minor gaps | 30-59 partial | 0-29 superficial.

## Writing Quality
500-800 words, clear thesis, ≥2 supported arguments, no factual errors, conclusion ties back, clean grammar.
Score: 90-100 all met | 60-89 minor gaps | 30-59 weak structure | 0-29 off-topic.

## API Uptime Evidence
7-day window, uptime % stated, source identifiable.
Score: 90-100 verifiable ≥99% | 60-89 ambiguous source | 30-59 partial window | 0-29 no evidence.
